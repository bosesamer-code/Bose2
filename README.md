## التشغيل المجاني

مسار الإنتاج في `src/free_production.py` لا يحتاج اشتراكًا مدفوعًا أو مفاتيح API. الصور والرسومات تُنشأ محليًا، لكن التعليق الصوتي العربي يستخدم خدمة Edge TTS عبر الإنترنت؛ لذلك يحتاج اتصالًا بالشبكة وقد يفشل مؤقتًا. عند فشل الصوت، يتوقف الإنتاج بدل إنشاء صوت وهمي أو صامت. المشاهد الافتراضية رسوم توضيحية مولّدة برمجيًا، وليست تصويرًا واقعيًا للمنتجات.

> لا نضع أي مفاتيح API أو كلمات مرور أو بيانات سرية هنا.

## تصوير حقيقي لليدين وصوت مسجّل (اختياري)\n\nيوجد مسار اختياري لاستخدام لقطات كروشيه حقيقية وصوت مسجّل من صاحب المحتوى، دون وجه أو أفاتار. يتطلب ملف صوت MP3 ومسارًا أو أكثر لفيديوهات MP4/MOV/MKV/WEBM، ويضيف عناوين عربية ويجهز فيديو 1080p. المسار مخصص للاستخدام الصريح فقط؛ لا يستنتج أن اللقطات حقيقية أو مرخّصة، ولا يرفع أو ينشر أي شيء. سير عمل GitHub Actions المجدول لا يستقبل تلقائيًا ملفات الهاتف، لذلك لا يعتبر المسار جاهزًا للتشغيل من الهاتف مباشرة حتى تتم إضافة طريقة آمنة لتمرير الملفات. التفاصيل: [docs/REAL_FOOTAGE_INPUTS.md](docs/REAL_FOOTAGE_INPUTS.md)، أو [افتح دفتر Colab المجاني للهاتف](https://colab.research.google.com/github/bosesamer-code/Bose2/blob/feature/real-hands-footage-mode/notebooks/real_crochet_footage_free_colab.ipynb).\n\n## مقدّمة فيديو متحركة اختيارية (SadTalker)

يمكن تشغيل مسار اختياري لإنشاء فيديو متحدث من صورة شخصية وصوت التعليق باستخدام [SadTalker مفتوح المصدر](https://github.com/OpenTalker/SadTalker). هذا المسار يحتاج تثبيت SadTalker وأوزان النماذج على جهاز/بيئة منفصلة، ويفضل GPU؛ وهو ليس مثبتًا داخل GitHub Actions المجاني، لذلك سيظل الإنتاج الآلي الحالي يستخدم الرسومات المتحركة البسيطة ما لم تُضبط المتغيرات التالية في بيئة التشغيل التي لديها SadTalker:

- `SADTALKER_DIR`: المسار المحلي لمجلد SadTalker الذي يحتوي `inference.py`.
- `SADTALKER_SOURCE_IMAGE`: مسار صورة واضحة لوجه المقدّمة، مع امتلاك حق استخدامها أو موافقة صاحبتها.
- `SADTALKER_PYTHON` (اختياري): مسار Python الخاص ببيئة SadTalker إذا كانت منفصلة عن بيئة المشروع.
- `CROCHET_BROLL_DIR` (اختياري): مجلد محلي يحتوي لقطات كروشيه مرخّصة بصيغ MP4/MOV/MKV/WEBM. تُستخدم اللقطات في مشاهد الشرح والتطبيق، وتظهر المقدّمة المتحركة في البداية والنهاية.
 
عند ضبط المتغيرين الأساسيين، يحوّل المسار الصوت إلى WAV، ويشغّل SadTalker، ثم يركّب مشاهد مختلطة مع الصوت الأصلي والعناوين العربية. إذا لم يتوفر `CROCHET_BROLL_DIR`، يستخدم رسومات المشروع الحالية في المشاهد التعليمية؛ لن يدّعي أنها لقطات حقيقية. إذا لم تُضبط متغيرات SadTalker، يستمر المسار المجاني الافتراضي. استخدم صورة تملك حق استخدامها أو لديك موافقة صاحبتها، ولا تستخدم صورة شخص حقيقي دون موافقته. SadTalker يحرّك الوجه والرأس بحسب الصوت، ولا ينشئ تلقائيًا تصويرًا واقعيًا لليدين وهما تنفّذان أعمال الكروشيه.

دليل التثبيت الرسمي والأوامر المدعومة: https://github.com/OpenTalker/SadTalker#quick-start
