## التشغيل المجاني

مسار الإنتاج في `src/free_production.py` لا يحتاج اشتراكًا مدفوعًا أو مفاتيح API. الصور والرسومات تُنشأ محليًا، لكن التعليق الصوتي العربي يستخدم خدمة Edge TTS عبر الإنترنت؛ لذلك يحتاج اتصالًا بالشبكة وقد يفشل مؤقتًا. عند فشل الصوت، يتوقف الإنتاج بدل إنشاء صوت وهمي أو صامت. المشاهد الافتراضية رسوم توضيحية مولّدة برمجيًا، وليست تصويرًا واقعيًا للمنتجات.

> لا نضع أي مفاتيح API أو كلمات مرور أو بيانات سرية هنا.

## مقدّمة فيديو متحركة اختيارية (SadTalker)

يمكن تشغيل مسار اختياري لإنشاء فيديو متحدث من صورة شخصية وصوت التعليق باستخدام [SadTalker مفتوح المصدر](https://github.com/OpenTalker/SadTalker). هذا المسار يحتاج تثبيت SadTalker وأوزان النماذج على جهاز/بيئة منفصلة، ويفضل GPU؛ وهو ليس مثبتًا داخل GitHub Actions المجاني، لذلك سيظل الإنتاج الآلي الحالي يستخدم الرسومات المتحركة البسيطة ما لم تُضبط المتغيرات التالية في بيئة التشغيل التي لديها SadTalker:

- `SADTALKER_DIR`: المسار المحلي لمجلد SadTalker الذي يحتوي `inference.py`.
- `SADTALKER_SOURCE_IMAGE`: مسار صورة واضحة لوجه المقدّمة، مع امتلاك حق استخدامها أو موافقة صاحبتها.
- `SADTALKER_PYTHON` (اختياري): مسار Python الخاص ببيئة SadTalker إذا كانت منفصلة عن بيئة المشروع.

عند ضبط المتغيرين الأساسيين، يحوّل المسار الصوت إلى WAV، ويشغّل SadTalker، ثم يدمج الصوت الأصلي والعناوين العربية في فيديو MP4. إذا لم تُضبط المتغيرات، يستمر المسار الافتراضي دون تغيير. استخدم صورة تملك حق استخدامها؛ لا تستخدم صورة شخص حقيقي دون موافقته. SadTalker يحرّك الوجه والرأس بحسب الصوت، ولا ينشئ تلقائيًا تصويرًا واقعيًا لليدين وهما تنفّذان أعمال الكروشيه.

دليل التثبيت الرسمي والأوامر المدعومة: https://github.com/OpenTalker/SadTalker#quick-start
