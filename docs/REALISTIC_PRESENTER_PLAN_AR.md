# خطة تطوير المقدّمة الواقعية — Bose2

## الهدف
إنتاج دروس كروشيه عربية مدتها 1–3 دقائق، بمقدّمة افتراضية بالغة مولّدة بالذكاء الاصطناعي ذات هوية بصرية ثابتة، وصوت عربي مصري واضح، ولقطات تنفيذ دقيقة للكروشيه.

## نتيجة مراجعة الملفات الحالية
- `src/free_media_providers.py`: مزوّد الصور المحلي يرسم شخصية توضيحية برمجيًا؛ لذلك لا يمكن للصوت وحده إزالة الشكل الكرتوني.
- `src/media_pipeline.py`: خط الإنتاج يفصل أنواع الوسائط ويجمع نتائج المزوّدات.
- `src/artifact_validator.py`: يتحقق من وجود ملفات الوسائط وصلاحيتها التقنية، لكنه لا يثبت وحده أن الشخصية متحركة أو أن الشرح التعليمي صحيح.
- `src/content_engine.py` و`content/content_catalog.json`: يحددان بنية الدروس والموضوعات؛ يلزم ضبطها لهدف 1–3 دقائق والتحقق من مدة النص المنطوق فعليًا.
- `.github/workflows/production-artifact.yml`: يشغّل الإنتاج والاختبارات والتحقق من الملفات، ويشترط المراجعة البشرية قبل النشر.

## خطة التنفيذ المتدرجة
1. **خط أساس آمن:** تشغيل الاختبارات الحالية وتسجيل النتيجة قبل تعديل مسار الإنتاج.
2. **هوية المقدّمة:** إضافة إعدادات مستقلة لوصف الشخصية المرجعية (ملامح عامة، ملابس، ألوان، أسلوب تصوير) وإعادة استخدامها بين الفيديوهات. لا تُخزّن أسرار أو بيانات اعتماد في هذه الإعدادات.
3. **الصوت:** الاحتفاظ بمزوّد الصوت الحالي كخيار أولي، والتحقق من ملف الصوت ومدته ووجود كلام مسموع؛ فشل الصوت يجب أن يفشل الإنتاج بوضوح بدل إنشاء صوت بديل صامت.
4. **تحريك الوجه:** إضافة مزوّد اختياري مستقل لمدخلات صورة مرجعية وصوت. لا يُعدّ هذا المزوّد متاحًا إلا إذا كانت أداة التشغيل والنماذج موجودة فعلًا؛ لا نفترض وجود GPU أو خدمة مجانية دائمة في GitHub Actions.
5. **لقطات تعليمية:** استخدام تصوير أصلي أو مواد مرخّصة لإظهار اليد والخيط والسنارة والغرز عن قرب. لا نعتمد على صور مولّدة لتأكيد خطوات كروشيه دقيقة.
6. **مدة الدرس:** تخطيط 60–180 ثانية من نص تعليمي فعلي، مع مقدمة قصيرة وخطوات مرتبة ومراجعة سريعة. قياس المدة من الصوت الناتج، لا من عدد المشاهد فقط.
7. **تحقق الحركة:** إضافة فحص/تقرير يوضح إن كان الفيديو يحتوي على حركة مرئية تتجاوز صورة ثابتة مكررة؛ الفحص الآلي إشارة مساعدة وليس بديلًا عن مشاهدة عينة.
8. **اختبار عينة خاصة:** إنتاج درس واحد قصير، وفحص الفيديو والصوت والترجمة يدويًا، وعدم رفعه للعامة تلقائيًا. يبقى النشر بموافقة صريحة.

## معايير القبول
- مدة نهائية بين 60 و180 ثانية.
- ملف MP4 صالح يحتوي مسار فيديو وصوت غير صامت.
- ترجمة عربية متزامنة مع الكلام.
- هوية المقدّمة متسقة مع المرجع بين المشاهد، مع حركة وجه فعلية عند توفر المزوّد.
- لقطات الكروشيه تشرح الخطوات الصحيحة بوضوح.
- لا نشر تلقائي ولا أسرار داخل المستودع العام.

## فصل Bose1 عن Bose2
- **Bose1 — مركز الأسرار:** يبقى منفصلًا لحفظ الأسرار وبيانات الاعتماد. لا تُنسخ مفاتيح API أو رموز الوصول إلى Bose2 أو ملفات الإعدادات العامة.
- **Bose2 — مدينة الإنتاج:** يحتوي على منطق إنشاء الدروس والوسائط والاختبارات وتقارير الإنتاج. تستخدم الأسرار المطلوبة عبر إعدادات GitHub Secrets المخصصة للمستودع، وبأقل صلاحيات لازمة.

## حدود التكلفة
تظل الأدوات مفتوحة المصدر والموجودة أصلًا هي الخيار الأول. جودة وواقعية الفيديو تعتمد على الموارد المتاحة؛ لذلك لن نعد بإنتاج واقعي كامل بلا تكلفة أو بموارد GPU مجانية دائمة. أي خدمة خارجية تُضاف لاحقًا يجب أن تكون اختيارية وألا تعطل المسار الأساسي عند غيابها.

## حالة التنفيذ الحالية
- أُضيف سير CI لتجميع ملفات Python وتشغيل مجموعة الاختبارات عند الدفع إلى فروع المشروع وفتح طلب دمج.
- عُدّل مُحسّن Gemini ليطلب نصًا مصريًا تعليميًا أطول (160–330 كلمة) ويرفض المخرجات الأقصر بدل اعتبارها مناسبة لفيديو 1–3 دقائق.
- أُضيف شرط في فحص الإنتاج يرفض الفيديو إذا كانت مدته أقل من 60 ثانية أو أكثر من 180 ثانية.
- **تأكيد الاختبارات الأحدث:** اكتمل تشغيل GitHub Actions رقم [38966421303](https://github.com/bosesamer-code/Bose2/actions/runs/38966421303) بنجاح، بما يشمل التجميع والاختبارات وفحص أسماء الملفات السرية.
- أُضيف اختبار يمنع استخدام الرسم الكرتوني بصمت عندما يكون وضع المقدّمة الواقعية مطلوبًا؛ وقد اجتاز الاختبار ضمن تشغيل CI الأحدث.
- أصبح سير الإنتاج يشترط وضع المقدّمة الواقعية؛ وبما أن SadTalker وصورة المرجع لم يُجهّزا بعد داخل بيئة الإنتاج، فمن المتوقع أن يتوقف إنتاج الفيديو بوضوح بدل إخراج فيديو كرتوني على أنه واقعي.
- أُضيف دليل مستقل لخيارات الذكاء الاصطناعي المجانية وحدودها في `docs/FREE_AI_TIERS_AR.md`.

## الخطوة التالية
تجهيز بيئة تشغيل فعلية لـ SadTalker وصورة مرجعية ثابتة للمقدّمة، ثم إضافة لقطات كروشيه أصلية أو مرخّصة. لا يتم الدمج إلى `main` أو نشر فيديو قبل اختبار عينة فعلية ومراجعتها. لا توجد مفاتيح سرية داخل المستودع، ولم يتم رفع أو نشر أي فيديو.
